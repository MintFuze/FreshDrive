# FreshDrive · Рейс

Мобильный журнал рабочих поездок с OLED-темой. Статическое приложение, без базы данных и подписок.

- Машины и расход на 100 км; маршруты с несколькими остановками и возвратом.
- Снимок цены и расхода для каждого рейса, оплата рейса и компенсация топлива.
- История по дням, статус оплаты, статистика и CSV.
- Координаты остановок, локальная схема и подробная карта OpenStreetMap по запросу (нужен интернет).
- JSON-копии для переноса между устройствами. Автоматической синхронизации нет.
- Офлайн после первого полного открытия и успешной установки service worker. Данные хранятся в localStorage этого браузера; очистка данных сайта удалит записи. Регулярно экспортируйте копию.

## GitHub Pages

Файлы сайта находятся в `dist`. Workflow публикует их после изменений в main. Если настройка Pages не включилась автоматически, откройте Settings → Pages → Source → GitHub Actions и перезапустите Publish FreshDrive. Ожидаемый адрес после успешного развёртывания: https://mintfuze.github.io/FreshDrive/ .

Откройте сайт онлайн на телефоне, затем добавьте на главный экран через меню браузера. Для iOS: Поделиться → На экран Домой. При смене адреса сайта данные не переносятся автоматически — используйте JSON-экспорт и импорт.

## Локально

Node.js 22+: `node preview.mjs`; адрес http://127.0.0.1:4173 . Проверки: `node --test tests/model.test.js`.

Километраж вводится вручную. Литры = км × расход / 100. Топливо = литры × цена. К получению = оплата за рейс + топливо при включённой компенсации. После топлива = к получению − топливо. Расход расчётный, без картографического расчёта расстояний.

Разработано для поездок на обработку яблок. Контекст: https://freshforma.ru/ . Приложение не является официальным продуктом компании.
