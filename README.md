# FreshDrive · Рейс

Мобильный журнал рабочих поездок с OLED-темой. Статическое приложение, без базы данных и подписок.

- Машины и расход на 100 км; маршруты с несколькими остановками и возвратом.
- Снимок цены и расхода для каждого рейса, оплата рейса и компенсация топлива.
- История по дням, статистика и CSV.
- Простой маршрут: откуда, куда и километраж каждого участка.
- JSON-копии для переноса между устройствами. Автоматической синхронизации нет.
- Офлайн после первого полного открытия и успешной установки service worker. Данные хранятся в localStorage этого браузера; очистка данных сайта удалит записи. Регулярно экспортируйте копию.

## GitHub Pages

Файлы сайта находятся в `dist`. Workflow публикует их после изменений в main. Если настройка Pages не включилась автоматически, откройте Settings → Pages → Source → GitHub Actions и перезапустите Publish FreshDrive. Ожидаемый адрес после успешного развёртывания: https://mintfuze.github.io/FreshDrive/ .

Откройте сайт онлайн на телефоне, затем добавьте на главный экран через меню браузера. Для iOS: Поделиться → На экран Домой. При смене адреса сайта данные не переносятся автоматически — используйте JSON-экспорт и импорт.

## Локально

Node.js 22+: `node preview.mjs`; адрес http://127.0.0.1:4173 . Проверки: `npm test` (расчёты, заказы, календарь).

Километраж вводится вручную. Литры = км × расход / 100. Топливо = литры × цена. Начислено = оплата за рейс + рассчитанная стоимость топлива. Цена за литр задаётся в настройках. Старые записи сохраняют прежние условия расчёта. После топлива = к получению − топливо. Расход расчётный, без картографического расчёта расстояний.

Разработано для поездок на обработку яблок. Контекст: https://freshforma.ru/ . Приложение не является официальным продуктом компании.

Цена бензина в настройках применяется только к новым заказам. Старые заказы сохраняют свою цену, включая нулевую. Чтобы добавить или исправить цену конкретного заказа, откройте его → «Изменить» → «Изменить стоимость бензина». Расчёт заказа, итоги и CSV обновятся после сохранения.

## Заказы и удобство

При ошибке чтения сохранённой базы приложение блокирует её перезапись. Можно скачать исходный файл и восстановить корректную JSON-копию в настройках. Успешное восстановление удаляет черновики от прежней базы.

- Нажатие на поездку открывает карточку с маршрутом по участкам, заказчиком, статусом и расчётами. Редактирование — отдельной кнопкой.
- Новый заказ по умолчанию имеет статус «В процессе». «Завершить заказ» включает его пробег и суммы в итоги. Старые записи без статуса считаются завершёнными. Статус можно изменить в редакторе; он не связан с оплатой.
- «Повторить поездку» переносит маршрут, машину, заказчика и оплату за рейс, ставит сегодняшнюю дату, статус «В процессе» и текущую цену бензина из настроек. Копия сохраняется только после подтверждения в форме.
- Сохранённые маршруты выбираются карточками с направлениями и общим километражем. Под полями виден расчёт по всем участкам, включая обратный путь.
- Заказчика можно выбрать из ранее введённых или ввести нового. Историю можно фильтровать по заказчику и статусу; поиск также учитывает заказчика.
- Черновики сохраняются при вводе отдельно для нового заказа и для каждой редактируемой записи. При повторном открытии формы можно продолжить черновик или начать заново. После сохранения заказа его черновик удаляется. Черновики хранятся только в этом браузере и не входят в JSON-экспорт.
- После удаления доступна кнопка «Вернуть». Можно последовательно вернуть несколько удалённых записей до перезагрузки страницы или импорта резервной копии.

Форма разделена на дату, заказчика и машину, маршрут, стоимость и детали. Статус выбирается двумя кнопками, машины — карточками с расходом, заказчики — плашками под полем ввода. В истории статус и заказчик также выбираются кнопками вместо системных списков. Итог и кнопка сохранения закреплены внизу формы.

Календарь открывается прямо в форме: «Сегодня», «Завтра» или «Выбрать дату». Неделя начинается с понедельника. Стрелки переключают месяцы, нажатие на название месяца позволяет выбрать месяц и ввести год. Дата меняется только после выбора дня; просмотр других месяцев не изменяет заказ. Клавиатура: стрелки перемещают фокус по дням, Home/End — начало/конец недели, PageUp/PageDown — месяц, с Shift — год, Enter выбирает день, Escape закрывает календарь. Выбранная дата сохраняется в черновике и не смещается из-за часового пояса.
